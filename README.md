# 英语点读小助手

一个给小朋友在 iPad / 手机上用的英语跟读小工具，纯前端单页应用，零服务器、零付费接口。

## 功能

- 输入英文或上传 `.txt` 文件，自动按句子分段（能识别 Mr./U.S. 等缩写和引号句）
- 点句子朗读，带逐词高亮跟读效果，支持连续朗读
- 点单词查看释义、音标和发音（在线免费词典 + 内置常用词兜底）
- 语速 0.6~1.2 可调（默认 0.8），可切换系统英语音色
- 内容保存在浏览器本地，不经过任何服务器

## 使用

直接访问：<https://nucleonshux.github.io/english-reader/>

或在 iPad 浏览器打开后「添加到主屏幕」，全屏使用。

## 技术说明

- 朗读：Web Speech API（iPad 系统自带语音，免费、可离线）
- 词典：[dictionaryapi.dev](https://dictionaryapi.dev) 免费接口 + 内置 200+ 常用词离线兜底
- 托管：GitHub Pages 免费静态托管
